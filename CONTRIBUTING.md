# Contributing 

Thanks for contributing to the project!
## Collaborators:

If you are a project collaborator:

1. Do not commit directly to main.
2. Create a new development branch before making changes:
3. git checkout -b your-branch-name
4. Make and commit your changes on your development branch.
5. Open a Pull Request (PR) from your branch into main.
6. PRs must have at least 1 approval before they can be merged.
7. Use a descriptive PR title that clearly explains what the PR changes.
8. Include a description of the changes in the PR, including relevant details about the commits and what was changed.


make sure to always pull from main before working !

Example
```
git checkout -b add-user-auth
# Make changes
git add .
git commit -m "Add user authentication"
git push -u origin add-user-auth
```

Then open a PR targeting main.

## Non-Collaborators:

If you are not a collaborator, please fork the repository and make your changes in your fork.
1. Fork the repository.
2. Clone your fork locally:
3. git clone <your-fork-url>
4. Create a development branch:
5. git checkout -b your-branch-name
6. Make and commit your changes.
7. Push the branch to your fork.
8. Open a Pull Request from your fork into this repository's main branch.
9. Please provide a descriptive PR title and a clear description of your changes.# Contributing
